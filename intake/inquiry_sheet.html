What happens after you submit this sheet

1. Car QR Showcase enters the details into the Edit Car form and generates the QR code.
2. You approve the QR preview, print the sticker and fix it to the windshield.
3. The dealer watches scans and enquiries arrive on the dashboard.
4. The QR URL can be changed at any time from one settings field - every sticker already printed keeps working.

How to use this sheet

The operator's side
  1. Collect. Hand this sheet to the dealer - or fill it in with them - for every vehicle that is getting a QR code. One sheet per vehicle.
  2. Check. Make and Model are filled in, the Description box actually lists the features, and photos are supplied.
  3. Enter. Admin panel - Cars - Add Car - paste each value into the matching field in the Edit Car form. Section J is the field-by-field map.
  4. Print the QR. In the same form pick the QR template, frame and shape, then print the sticker and fix it to the windshield.
  5. Batch alternative. Fill the Intake Ledger spreadsheet instead, then use Cars - Bulk Import and upload it as a CSV. One file per dealer.

K

Traps to avoid

Check these before you save
Make and Model are the only hard blocks
The form refuses to save without both. Everything else can be empty and added later.
Set Make before Model
Changing the Make clears the Model. Enter them in the wrong order and you lose the model.
There is no separate features field
The customer page renders Description, fuel type, colour, mileage, price, photos, the specifications and the contact details. Features written anywhere else are invisible - put them in Description (section C).
Number of owners is the only leftover in Description
Engine, horsepower and condition now have their own fields. Owners does not - put it in Description.
Do not use commas in Description or Location
The CSV bulk importer splits rows on commas, so one comma shifts every column after it. Use ' - ' or ' ; '. The Edit Car form is not affected.
One company per bulk import
The importer assigns every row to the company chosen in step 2. Split the file if the vehicles belong to different dealers.
WhatsApp formatting
The form strips a leading 00 and a single leading 0 on long numbers. Enter 009647701234567 and it is stored correctly.
Photos are the product
A vehicle with no photos still scans, but it will not sell. Six good photos is the practical minimum for a dealer listing.
